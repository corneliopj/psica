# Instruções do Agente para este repositório

Objetivo
- Garantir que nomes de pastas, classes e arquivos de código-fonte do sistema sejam escritos em Português.

Escopo (aplica-se a)
- Código-fonte do aplicativo: `app/`, `routes/`, `resources/views/`, `database/migrations/`, `app/Http/Controllers/`, `app/Models/`, `app/Http/Requests/`, `app/View/Components/`.
- Nomes de classes, nomes de arquivos de código (PHP, Blade, JS/CSS do app), nomes de rotas exibidas ao usuário e labels persistentes.

Regras principais
- Use Português (pt-BR/PT-PT) consistente para: nomes de pastas, nomes de arquivos e nomes de classes. Ex.: `Paciente`, `PacienteController`, `Prontuario`, `Agendamento`.
- Use forma singular para nomes de classes (`Paciente`) e plural em snake_case para nomes de tabelas (`pacientes`).
- Arquivos PHP de classes devem usar PascalCase no nome do arquivo e da classe: `app/Models/Paciente.php` com `class Paciente`.
- Controllers e Requests: `PacienteController.php`, `PacienteRequest.php`.
- Views Blade: nomes em português e snake_case/ kebab-case adequados: `resources/views/pacientes/index.blade.php`, `resources/views/prontuarios/show.blade.php`.

Convenções adicionais
- Rotas: prefira rotas em português no arquivo `routes/web.php`: `Route::resource('pacientes', PacienteController::class);`.
- Mensagens exibidas ao usuário (flash messages, labels) devem estar em Português.
- Migrations: o arquivo pode manter o timestamp do Laravel, mas o nome da tabela deve estar em português plural (`pacientes`, `prontuarios`, `agendamentos`).

Exceções
- Não traduzir nomes de pacotes externos (composer.json, vendor/*), scripts de build (`package.json`), ou arquivos de infraestrutura gerados automaticamente (ex.: `vite.config.js`, `composer.lock`).
- Variáveis de ambiente e chaves técnicas podem permanecer em inglês quando for padrão do framework (ex.: `DB_HOST`, `APP_KEY`).

Como aplicar (passos recomendados)
1. Ao criar novos modelos/controllers/views, escolha nomes em Português conforme as regras.
2. Ao refatorar código existente, renomeie arquivos e atualize referências (composer autoload, imports/uses, chamadas de rota) para evitar quebras.
3. Atualize migrations/seeders para usar os nomes de tabela em português; escreva migrations de migração/renomeação quando necessário.

Verificação/Exemplos de prompt para o agente
- "Crie um model Eloquent chamado `Paciente` com migration para tabela `pacientes` e controller `PacienteController`."
- "Scaffold views Blade para `pacientes` (index/create/edit/show) usando Tailwind e nomes de arquivos em português."

Observações/Notas
- Esta instrução é um requisito de estilo do projeto: trate-a como uma regra forte para o código-fonte da aplicação.
- Se houver dúvidas sobre tradução (ex.: termos técnicos), pergunte antes de aplicar refatoração em massa.

Se sim, eu aplico as mudanças e executo testes básicos de migração.
